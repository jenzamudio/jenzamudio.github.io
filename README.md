# Jennifer Zamudio Academic Website

## Main files

- `index.html` — homepage
- `research.html` — research program
- `publications.html` — publications
- `presentations.html` — presentations
- `teaching.html` — teaching
- `about.html` — biography and education
- `cv.html` — CV page
- `css/style.css` — global design and spacing
- `js/main.js` — mobile navigation
- `images/` — add photos and figures here

## Before publishing

Replace placeholder text, links, email address, and your photo. For the CV button, create a `files` folder and add `Jennifer-Zamudio-CV.pdf`.

## GitHub Pages

Create a repository named `YOURUSERNAME.github.io`, upload the contents of this folder, then enable GitHub Pages from Settings → Pages using the `main` branch and root folder.
